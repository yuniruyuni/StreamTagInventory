Stream Tag Inventory に戻る

プライバシーポリシー

第1版 · 2026年11月22日制定

この方針は、ゆにるユニが運営する Stream Tag Inventory の公式サービスに適用されます。

Twitch ログインと連携

Twitch アカウントでログインすると、アカウントの識別子を使って本人を確認し、そのアカウントの配信テンプレートを読み込みます。ブラウザは認証用トークンをタブのセッションストレージに保持し、ログインの往復を確認するための一時的な値をローカルストレージに保存します。

配信テンプレートと Twitch への送信

作成したタイトル・カテゴリ・タグなどのテンプレートをブラウザ内に保存し、アカウントに紐付けてサーバーと同期します。テンプレートを適用すると、選んだ設定を Twitch API に送ってチャンネルの配信情報を更新します。配信中はストリームマーカーも作成します。

テンプレートはアプリ内で削除できます。アプリへのアクセス許可は Twitch の接続設定で取り消せます。

ログイン利用者数の集計

利用状況を把握するため、日本時間の日ごとに、ログイン状態で利用したアカウントを重複を除いて数えます。サービス内でアカウント識別子を専用の鍵と日付で変換し、自営の集計システム Yuniview にはその日の識別用の値を送ります。日別の識別用の値は直近30日分を保持し、古いものから削除します。

配信タイトル、タグ、テンプレート本文、認証用トークンは、この利用者数の集計に使いません。

現在は日をまたいで同じアカウントを照合する月間集計を行っていません。月間集計を導入する場合は、目的、照合できる期間、保存期間を開始前にこのページでお知らせします。

接続情報と運用ログ

サイトの配信や保護のため、Cloudflare およびサービスのサーバーが IP アドレス、アクセス日時、リクエスト先などの接続情報を処理します。運営者はアクセスログや応答時間、エラーの記録を、障害の調査や不正利用の防止に利用します。

お問い合わせと改定

情報の取り扱いや削除についてのお問い合わせは、運営者 ゆにるユニの公式サイトに掲載している連絡先からお寄せください。取り扱いを変更したときはこのページを改定し、更新日を表示します。
