# Visual Regression Testing (VRT)

このプロジェクトでは、[easy-vrt](https://github.com/yorifuji/easy-vrt)を使用してVisual Regression Testingを実装しています。

## セットアップ

### 初回セットアップ

初めてVRTを実行する場合、ベースラインとなるスクリーンショットを作成する必要があります：

```bash
# 依存関係のインストール
bun install

# Playwrightブラウザのインストール
bunx playwright install chromium

# ベースラインスクリーンショットの作成
bun run vrt:update
```

## 使用方法

### ローカルでのVRT実行

```bash
# VRTテストの実行（既存のスクリーンショットと比較）
bun run vrt

# スクリーンショットの更新
bun run vrt:update

# Playwright UIでVRTを確認
bun run vrt:ui
```

### CI/CD

プルリクエストを作成すると、自動的にVRTが実行されます：

1. ベースブランチ（main）のスクリーンショットを生成
2. PRブランチのスクリーンショットを生成
3. 両者を比較してビジュアルの差分を検出
4. PR上にコメントとして結果を表示

## テストケース

以下の画面のスクリーンショットを取得しています：

### 未認証状態
- ログイン画面

### 認証済み状態
- メインインベントリ画面
- テンプレートカード
- カテゴリドロップダウン
- タグ入力インターフェース
- ユーザーメニュードロップダウン
- 変更済みテンプレート（保存/元に戻すボタン表示）

### レスポンシブ
- モバイルビュー（375x667）
- タブレットビュー（768x1024）

## トラブルシューティング

### スクリーンショットの差分が検出される場合

1. 意図的なUI変更の場合：
   ```bash
   bun run vrt:update
   ```
   を実行して新しいスクリーンショットを承認します。

2. 意図しない変更の場合：
   - PRのコメントで差分を確認
   - 問題を修正してから再度プッシュ

### フォントやレンダリングの微細な差分

OSやブラウザのバージョンによって微細な差分が発生する場合があります。
この場合は、`playwright-vrt.config.ts`で閾値を調整することができます。

## 注意事項

- スクリーンショットはGitリポジトリにコミットしません（.gitignoreで除外）
- CI環境では常に同じ環境（Ubuntu + Chromium）で実行されるため、一貫性が保たれます
- ローカル環境でスクリーンショットを更新する場合は、CI環境との差異に注意してください
