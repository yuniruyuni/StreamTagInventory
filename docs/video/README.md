# remotion

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.3. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

## Browser ZIP extraction security

This is an independent Bun project, outside the root workspace. Install and test
from `docs/video`; root workspace installs and audits do not cover this lockfile.

```bash
bun install --frozen-lockfile
bun run test:security
```

`patchedDependencies` applies `patches/extract-zip@2.0.1.patch` to the dependency
loaded by Remotion 4.0.434's browser downloader. It addresses
[GHSA-jmr9-qjv8-65gv](https://github.com/advisories/GHSA-jmr9-qjv8-65gv) and
[GHSA-7pqw-9j4j-h8q3](https://github.com/advisories/GHSA-7pqw-9j4j-h8q3) by:

- Rejecting every archive symlink, including links whose targets stay in the
  extraction directory.
- Rejecting escaping/platform-specific paths and normalized duplicate entries.
- Checking each parent directory without following symlinks before descending,
  and creating files exclusively so existing files, hardlinks and leaf symlinks
  cannot be overwritten.

Tests create ZIPs and extraction directories under a temporary directory, resolve
the exact `extract-zip` instance used by Remotion, and verify that rejected
archives leave outside files and directories unchanged. The extraction directory
must be trusted and not concurrently modified by another process; this portable
patch does not provide protection against a local process racing parent-directory
replacement.

The supported browser path is Remotion's default Chrome Headless Shell, whose
macOS arm64 144.0.7559.20 archive was downloaded, extracted and launched with this
patch. Archives requiring symlinks, such as some full Chrome app bundles, fail
closed. Existing files also cause extraction to fail; remove an incomplete
extraction directory before retrying. Remotion normally clears a partial browser
directory when its version marker is missing or mismatched.

The package remains version 2.0.1: neither advisory lists an upstream patched
version. Version-based scanners can still report both findings. This patch is a
local mitigation, does not suppress those reports, and is not a zero-findings
claim. Review the patch and rerun these tests before updating Remotion or
`extract-zip`.

The existing video type check and composition bundle require the uncommitted
`src/highlights.json` generated by `bun run capture`. Missing capture output is a
separate prerequisite; these security tests do not generate or alter video assets.
